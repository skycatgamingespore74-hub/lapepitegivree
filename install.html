❄️ La Pépite Givrée — Installer l'application

Guide simple pour télécharger et installer l'APK en toute sécurité
Étape 1 — Télécharger

Tape sur le bouton "Installer l'APK" pour récupérer le fichier. Le téléchargement démarre depuis lapepitegivree.fr.

Étape 2 — Autoriser l'installation

Ouvre Paramètres → Applications → Installer des applications inconnues, et autorise Chrome (ou ton navigateur).

Étape 3 — Installer

Ouvre le fichier .apk téléchargé, confirme l'installation puis appuie sur "Ouvrir" pour lancer l'application.

Étape 4 — Autoriser les notifications

Active les notifications pour recevoir les nouveautés et offres spéciales.

Étape 5 — C'est prêt !

Retrouve La Pépite Givrée sur ton écran d'accueil et profite de l'expérience.
